# MFSTNet — pinned dependencies (NFR-08: clean-machine reproduction)
#
# Versions are PINNED, not ranged. A range that resolves differently in
# November than it did in August breaks reproducibility silently.
#
# Every version below is the one this environment actually runs, read from the
# installed distributions rather than chosen by hand. That is the point: a pin
# nobody has run is a guess, and until 2026-08-20 this file was full of them —
# 21 of 35 lines were ranges despite the paragraph above, and not one of the
# seven pinned-and-installed packages matched its pin (stable-baselines3
# declared ==2.3.2 against 2.9.0 installed; SUMO ==1.19.0 against 1.27.1).
#
# When anyone adds a dependency, they add the pinned line in the SAME commit.
#
# Audited 2026-08-18 by walking the AST of every source file and comparing the
# imports against this file, in BOTH directions. Re-audited 2026-08-20 against
# the installed environment, which is the direction the first audit missed.
# tests/test_requirements_complete.py runs both.
