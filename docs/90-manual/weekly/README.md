# Weekly Status Records

One file per week: `W00.md`, `W01.md`, … `W20.md`.

Copy [`docs/templates/weekly-status.md`](../../templates/weekly-status.md), fill it in every Friday,
commit it. Fifteen minutes.

Two reasons this is worth the time. It is the raw material for the final report — a project
reconstructed from memory in Week 20 loses the detail that mattered. And it is where slippage becomes
visible early enough to act on: a milestone marked "at risk" in Week 6 can still be recovered, the
same milestone discovered missing in Week 13 cannot.

The RTM check in §7 of the template is the standing task that keeps traceability from rotting.
