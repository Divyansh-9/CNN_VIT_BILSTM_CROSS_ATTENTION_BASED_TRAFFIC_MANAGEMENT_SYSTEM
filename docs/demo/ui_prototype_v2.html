How to read these numbers

These are forecasts, not measurements. The vehicle number is an average across the next 60 seconds, so it can be a fraction, and it counts vehicles in view, not vehicles passing through. Levels are set separately for each camera, so HIGH here is not the same amount of traffic as HIGH elsewhere. Level and number are two separate forecasts and may not always match. Counted values exclude bicycles; forecasts include them.
